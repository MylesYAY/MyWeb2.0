# MyWeb2.0

A slick, Google-inspired experience with a blue accent. Search Wikipedia definitions, explore images, and use `/commands` to multitask quickly—all with light and dark themes.

## Getting started

1. Open `index.html` in your browser (or run a static server such as `python -m http.server 8000`).
2. Use the central search bar:
   - Type anything to search Wikipedia definitions and related images at once.
   - `/wiki topic` for definitions only.
   - `/image topic` for image search.
   - `/both topic` for definitions + images.
   - `/dark` or `/light` to switch themes.
   - `/clear` to reset the UI.
3. Keyboard: press <kbd>Ctrl/Cmd + K</kbd> to focus the search box.
